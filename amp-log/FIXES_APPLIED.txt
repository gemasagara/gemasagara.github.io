HOW TO RESTART AND TEST
================================================================================

STEP 1: Kill any running server
  Press Ctrl+C in the terminal running "npm start"

STEP 2: Clean install
  cd ~/Programming/Portfolio
  rm -rf node_modules
  rm package-lock.json
  npm install
  npm install --save express

STEP 3: Start the server
  npm start

EXPECTED OUTPUT:
  ✅ Admin Manager initialized
  ╔════════════════════════════════════════╗
  ║  Portfolio Admin Server                ║
  ║  Running on http://localhost:3000      ║
  ║  Admin panel: http://localhost:3000/admin.html ║
  ╚════════════════════════════════════════╝

STEP 4: Clear browser cache
  Chrome/Firefox: Ctrl+Shift+Delete (or Cmd+Shift+Delete on Mac)
  Then refresh the page

STEP 5: Open admin panel
  http://localhost:3000/admin.html
  
  DO NOT USE: 127.0.0.1:3000 (use localhost instead)

STEP 6: Verify it works
  ✅ Admin panel displays
  ✅ Sidebar visible
  ✅ Dashboard loads
  ✅ Blogs section accessible
  ✅ "Add New" button visible
  ✅ No errors in browser console

STEP 7: Create test blog
  1. Click "Blogs" in sidebar
  2. Click "Add New"
  3. Fill form fields
  4. Write markdown content
  5. Click "Create"
  6. See success message
  7. Check: ls -la data/blogs/posts/

================================================================================
QUICK DIAGNOSIS
================================================================================

If something still isn't working:

1. Check server terminal
   - Look for red error messages
   - Should see "✅ Admin Manager initialized"

2. Check browser console (F12)
   - Should see: "BlogAPI initialized with baseUrl: http://localhost:3000/api"
   - No "process is not defined" error
   - No other red errors

3. Check network tab (F12 → Network)
   - admin.html should load (200)
   - /api/blogs/metadata should load (200)
   - No 404s or failed requests

4. If still failing:
   - Kill server (Ctrl+C)
   - Delete node_modules: rm -rf node_modules
   - Reinstall: npm install && npm install --save express
   - Start: npm start
